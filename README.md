# Tabuada em C

Projeto simples desenvolvido em linguagem C para exibir a tabuada de multiplicação de um número informado pelo usuário.

## 💻 Tecnologias Utilizadas

- Linguagem C
- Compilador MinGW (GCC)
- Code::Blocks / Visual Studio Code

## 📋 Descrição

Este programa pede que o usuário informe um número inteiro, e em seguida exibe a tabuada de 1 a 10 para esse número.

### 🧠 Lógica utilizada

- `for` para percorrer os multiplicadores (de 1 a 10)
- `printf` para exibir cada linha formatada

## ▶️ Como executar

1. Compile o arquivo `tabuada.c` com um compilador C (como GCC):
   ```bash
   gcc tabuada.c -o tabuada.exe
